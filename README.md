## Hi, I'm Mel 👋

I've spent 20 years inside brand, marketing, retail, tech, and revenue operations, and I kept running into the same wall: businesses aren't lacking people with skills, they're lacking systems to harness them effectively.

So systems are what I build now. I'm a marketing and brand strategist working in the AI era, and I run [Mel Greene Consulting](https://melgreene.com) from Vancouver. I help marketing and brand leaders actually use AI: strategy first, then the working system that delivers it.

### What's here

Everything I publish on GitHub is a system I really run in my own business. My repos are receipts.

**[reel-edit-system](https://github.com/mel-greene/reel-edit-system)** — the complete editing system an AI agent uses to edit my Reels: a written spec that encodes my editing taste, a Remotion component kit that enforces it, and a worked example. A new video is a 15-line brief. My review notes become permanent rules, so the system gets sharper with every edit instead of starting over.

More systems are coming as I clean them up for the public: content pipelines, research workflows, and the automation behind my weekly publishing.

### Why I publish the real thing

Taste and strategy don't survive being re-derived every time you need them. Writing them down is the whole trick, and a written system is something an AI agent can execute while you stay the one deciding when the taste changes.

If you take one of these systems, rip out my rules and write in yours. That's the point.
